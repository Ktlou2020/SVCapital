Firebase Data Migration

Upload any combination of the JSON export files from the previous platform. All files are optional — only the data you provide will be imported. Safe to run multiple times — existing records are updated, not duplicated. userAccountNumber is always the unique identifier.

Post-Migration Utilities

Recalculate Pool Statistics

Recomputes investor_count, raised_amount, and current_invested for every pool from live investment data. Safe to run at any time.

Backfill Orphan Pool Records

Finds any investments that reference a pool_id with no matching pool record (e.g. pools that were in Firebase but missing from the JSON export) and automatically creates stub pool records from the investment data. Safe to run multiple times.

Backfill FICA Approval from KYC Status

Finds every investor whose kyc_status is already approved and sets their fica_status to approved and account to active. Also syncs the reverse direction. Safe to run multiple times.
